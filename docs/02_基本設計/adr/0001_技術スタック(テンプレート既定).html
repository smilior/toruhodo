ADR-0001 技術スタック（Historical）

確定メモ

本 ADR は撮るほどの技術選定としては使用しない。Historical 記録のみ。

ステータス

Superseded by ADR-0003

日付

Historical（記録のみ）

本文

ドキュメント骨格に含まれていた初期の技術選定メモである。撮るほどの現行スタックは Next.js + Vercel + Turso + Better Auth + Google OAuth に Claude Vision・Vercel Blob・MapLibre を加えた構成であり、技術選定の正は ADR-0003 のみとする。本ファイルの旧内容を実装や設計の指針にしてはならない。
