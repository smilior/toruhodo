02 基本設計 · ADR-0003

ADR-0003 撮るほど技術スタック（Vercel + Turso + Better Auth + Claude + Blob + MapLibre）

撮るほど（toruhodo）の技術選定の正。menva 同型の Web クラウド基盤に、Vision AI・写真 Blob・地図を加えた構成とする。ファイル名は履歴互換のため維持する。

確定メモ

本 ADR は ADR-0001 および ADR-0002 を supersede する。設計書・実装は本 ADR のみを参照する。ドメイン・UI の詳細は PRODUCT_BRIEF と企画書 README を正とする。

ステータス

Accepted

日付

2026-07-20

背景

撮るほどはスマホカメラで石碑・案内板を撮影し、AI がやさしい言葉で解説する B2C 向け PWA である。機種変更後も旅の記録が残り、OCR＋解説のサーバー側実行と写真保管が必要である。端末ローカルのみではバックアップとマルチデバイスに弱い。一方でネイティブ配信や大規模基盤は MVP に過剰である。menva 同型の Next.js + Vercel + Turso + Better Auth を土台に、Claude Vision・Vercel Blob・MapLibre を追加し、ドメイン（やさしく教える UI・1 タップ撮影・旅の記録帳）に集中する。

決定

層 採用
フレームワークNext.js 16 App Router + React 19 + TypeScript
ホスティングVercel（本番）/ next dev（ローカル）・PWA 配信
DBTurso (libSQL) + Drizzle ORM + @libsql/client
ローカル DBturso dev --db-file local.db → http://127.0.0.1:8080
認証Better Auth + Google OAuth（GCP）
写真ストレージVercel Blob（records.photo_url）
AIClaude API（Vision）。1 リクエストで OCR＋解説 JSON
地図MapLibre GL JS（クライアント）
ミューテーションServer Actions / Route Handlers
スタイルTailwind CSS v4 + shadcn/ui + デザイントークン（Shippori Mincho / Zen Maru Gothic）
ドメインテーブルrecords / user_settings
認証テーブルusers / sessions / accounts / verifications
 
Browser（PWA）
  → Next.js App Router on Vercel
       ├ Middleware: session cookie ゲート
       ├ Better Auth（/api/auth/*）→ Google OAuth
       ├ Server Actions / Route Handlers
       │    ├ Vercel Blob（写真）
       │    └ Claude Vision（OCR＋解説・server-only）
       ├ Drizzle → Turso（records, user_settings, auth）
       └ MapLibre（旅の記録地図）

検討した代替案と却下理由

代替案却下理由
静的 Web + 端末内のみ永続（旧ローカルファースト案）機種変更・バックアップに弱い。AI・写真を端末完結にするコストが高い（ADR-0002）
ネイティブアプリ（App Store / Play）PWA で十分。配信・更新コストが高い（OUT-01）
オフライン完全同期・オフライン OCRMVP 外。後続候補（OUT-02）
汎用ドキュメント OCR 基盤石碑・案内板特化でスコープを絞る（OUT-05）

影響・制約

  • Google ログインが必須。未認証はアプリ画面に入れない。
  • データはユーザー単位。複数人共有は MVP 外。
  • Claude / Blob 利用にネットワークと API コストが発生する。
  • 環境変数は .env.example を正とする（Turso / Better Auth / GCP / Blob / Anthropic）。
  • prototype/ は UI 参照用。本番実装は src/。
  • UI 原則（やさしく教える・1 タップ撮影・原文と AI 補足の区別・中高年配慮）は企画書どおり維持。
  • ADR-0001 / ADR-0002 は Historical / Superseded。実装ガイドとして使わない。
