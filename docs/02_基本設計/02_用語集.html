02 基本設計 · 02/07

用語集

撮るほどのドメイン用語と技術用語を定義する。設計・実装・受け入れで同一の語を用いる。

確定メモ

ドメインの正は docs/_spec/PRODUCT_BRIEF.md と企画書 README。UI 文言はユーザー向けにひらがな寄り、内部識別子は英語（records, partial 等）を用いる。

プロダクト・ブランド

用語定義
撮るほどアプリ表示名・ブランド名。タグライン「かざすと、やさしく教えてくれる」。
toruhodoプロジェクトコード名。リポジトリ・環境識別に用いる。
朱印ロゴ朱色正方形に白の「撮」1 文字（Shippori Mincho）。ワードマーク「撮るほど」と併記。PWA アイコンにも使用。

ドメイン用語

用語定義
旅の記録 / Record1 回の撮影・解説結果をまとめた永続エンティティ。テーブル名 records。写真 URL・解説文・位置・メモ等を持つ。
OCR撮影画像から文字を読み取ること。Claude Vision が OCR 原文（ocrRaw）を返す。
ocrRawAI が読み取った原文テキスト。結果画面では主に内部保持し、やさしい／くわしい言いかえの根拠となる。
やさしい（easy）原文を平易に言いかえた解説モード。既定の modeDefault。
くわしい（detail）原文にそったより詳しい解説モード。
ふりがな / rubyHTML <ruby> による読み仮名。easyRuby / detailRuby として保存。表示 ON/OFF は結果画面ローカル状態（rt の表示切替）。
原文カード結果画面の「ここに書かれていること」カード。古紙グラデ地。やさしい／くわしいの本文を表示。
AI補足カード結果画面の「AIによる補足」カード。薄藍地。背景知識（aiNote）。原文カードと色・アイコン・ラベルの 3 重で区別する。
aiNoteAI による補足・背景知識テキスト。
partial一部のみ読めた状態。注意バナーと読めた文字チップを表示。
partialChars部分読み取り時に読めた文字の表示用文字列。
failedテキスト検出失敗。読み取り失敗 UI（デザイン 1h）へ。
スキャン状態機械idle → capturing → ocr → generating → done | failed | partial。
メモ（memo）ユーザーが結果に書き足す自由記述。保存後も編集可。
位置情報lat / lng / placeName。geoEnabled が false または拒否時は null 可。記録自体は可能。
UserSettingsユーザー設定。furiganaDefault / modeDefault / geoEnabled。

画面・UI

用語定義
かざして解説ホーム主役 CTA。撮影画面（S-02）へ遷移する。
デザインID企画書 UI デザインの画面識別子（1b〜1l 等）。
タブバーホーム / 履歴 / 地図 / 設定の 4 タブ。
免責注記結果画面最下部の常時表示文「AIによる解説です。正確な情報は現地の案内をご確認ください。」

技術用語

用語定義
Better Auth認証ライブラリ。Google OAuth とセッション Cookie を提供。/api/auth/*。
TursolibSQL ベースのクラウド DB。records / user_settings / 認証テーブルを保持。
DrizzleTypeScript ORM。スキーマ正本は src/lib/db/schema.ts。
Vercel Blob撮影写真のオブジェクトストレージ。records.photoUrl に URL を保存。
Claude VisionAnthropic Claude の画像入力 API。OCR＋解説 JSON を 1 リクエストで取得。
MapLibreMapLibre GL JS。旅の記録地図（S-06）でピン表示に用いるクライアントライブラリ。
Server ActionsNext.js のサーバー側ミューテーション。records 保存・メモ更新・設定変更等。
Middlewareセッション Cookie による保護ルートのゲート。未ログインは S-00 へ。
PWAProgressive Web App。モバイルファーストの Web アプリとして配信。
nanoid / cuidレコード ID 生成方式。文字列 PK。
