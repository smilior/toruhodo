02 基本設計 · 05/07

データベース論理設計書

撮るほどのエンティティと Turso 論理テーブルを定義する。正本は実装時の src/lib/db/schema.ts および PRODUCT_BRIEF の Record モデル。

確定メモ

DB は Turso（libSQL）+ Drizzle ORM。写真実体は Vercel Blob に置き、DB には URL のみ保持する。派生値は永続化しない（画面ローカルの mode / furigana 表示状態など）。

永続化方針

  • エンジン: Turso / libSQL（SQLite 互換）
  • アクセス: Drizzle ORM（@libsql/client）
  • 所有境界: records.user_id / user_settings.user_id → users.id
  • 写真: Vercel Blob。削除時は Blob オブジェクトも可能な範囲で削除
  • 派生値: 結果画面の mode / furigana はクライアント状態。DB に持たない

命名規則

区分 規約 例
テーブルsnake_case 複数形records, user_settings, users
カラムsnake_caseuser_id, photo_url, easy_text

論理 ER

User 1 ── * Record
User 1 ── 0..1 UserSettings

User（Better Auth）
├ id, name, email, email_verified, image
└ created_at, updated_at

Record（旅の記録）
├ id (PK)
├ user_id (FK → users.id)
├ photo_url
├ title, easy_text, detail_text
├ easy_ruby, detail_ruby, ai_note, ocr_raw
├ partial, partial_chars
├ lat, lng, place_name
├ memo
└ created_at
  INDEX (user_id), INDEX (user_id, created_at)

UserSettings
├ user_id (PK, FK → users.id)
├ furigana_default (bool, 既定 true)
├ mode_default ("easy" | "detail", 既定 "easy")
└ geo_enabled (bool, 既定 true)

Better Auth 付帯:
  sessions (user_id), accounts (user_id), verifications

属性詳細（論理）

users（Better Auth 標準）

カラム型必須説明
idtext PK必須ユーザー ID
nametext必須表示名
emailtext unique必須メール
email_verifiedinteger bool必須既定 false
imagetext任意アバター URL
created_at / updated_attimestamp必須監査

sessions / accounts / verifications は Better Auth 既定スキーマに従う。

records

カラム型必須説明
idtext PK必須nanoid / cuid
user_idtext FK必須所有者。users.id
photo_urltext必須Vercel Blob URL
titletext必須AI 生成の短い題名
easy_texttext必須やさしい言いかえ（プレーンまたは HTML）
detail_texttext必須くわしい説明
easy_rubytext必須やさしい＋<ruby> HTML
detail_rubytext必須くわしい＋<ruby> HTML
ai_notetext必須AI 補足・背景知識
ocr_rawtext必須OCR 原文
partialinteger bool必須一部のみ読めた
partial_charstext任意読めた文字チップ用
latreal任意緯度
lngreal任意経度
place_nametext任意場所名表示用
memotext任意ユーザーメモ
created_attimestamp必須作成日時

user_settings

カラム型必須説明
user_idtext PK FK必須users.id
furigana_defaultinteger bool必須既定 true
mode_defaulttext必須easy | detail。既定 easy
geo_enabledinteger bool必須位置情報記録。既定 true

永続化しないもの

  • 結果画面ローカルの mode / furigana（表示状態）
  • スキャン中間状態（idle / capturing / ocr / generating）
  • 地図のビューポート・ズーム
  • 写真バイナリ本体（Blob 側）
