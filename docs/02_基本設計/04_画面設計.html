02 基本設計 · 04/07

画面設計書

撮るほどの画面一覧（S-00〜S-07）、デザイン ID 対応、主要 UI 要素と遷移、企画書に基づくレイアウト要点を定義する。

確定メモ

UI 正本は docs/00. 企画書/README.md と 撮るほど UIデザイン.dc.html。色・タイポ・余白は hifi。本文 16px 以上、タップ 44px 以上、主ボタン高さ 56px。設定画面はデザイン未作成のため shadcn リストで実装する。

画面一覧

画面ID 名称 パス デザインID 認証
S-00ログイン/login（未作成・shadcn）不要
S-01ホーム/1b要
S-02撮影/scan1c, 1d要
S-03解説結果/result/:id1e, 1f, 1g, 1i要
S-04読み取り失敗/scan 内 or /result/failed1h要
S-05履歴/history1j, 1k要
S-06地図/map1l要
S-07設定/settings（未作成・shadcn）要

タブバー: ホーム / 履歴 / 地図 / 設定（4 タブ）。撮影・結果はタブ外フロー。

画面遷移

S-00 ログイン
  └→ S-01 ホーム ⇄ S-05 履歴 ⇄ S-06 地図 ⇄ S-07 設定（タブ）
           │
           └→ S-02 撮影 → (1d ローディング)
                    ├→ S-04 失敗 → 再撮影 or S-01
                    └→ S-03 結果（done / partial）
                         ├ 記録に残す → S-05 に出現
                         └ 履歴・地図のピンから再表示

レイアウト要点（企画書対応）

画面 主要 UI 要素 レイアウト要点
S-00 ログイン Google ログインボタン、ロゴ、タグライン shadcn 標準。生成り背景・朱 primary。未作成デザインに合わせる
S-01 ホーム (1b) 朱印ロゴ＋ワードマーク、「かざして解説」CTA、さいきんの記録、タブバー 縦 flex。朱角丸 26px の主役ブロック。履歴カード 2〜3 件。「すべて見る」→ S-05
S-02 撮影 (1c) カメラ全面、閉じる、ヒントピル、ガイド枠、ギャラリー／シャッター／フラッシュ ダーク地 #221F1A。シャッター外輪 80px・内円 60px 朱
S-02 読取中 (1d) 暗幕、ボトムシート、2 段階スピナー（OCR→解説）、キャンセル 「読み取っています…」→「解説を作っています…」
S-03 結果 (1e–1g) 写真、タイトル、メタ、モードセグメント、ふりがな SW、原文カード、AI補足カード、メモ、記録に残す、免責 縦スクロール 1 カラム。原文＝古紙／AI＝薄藍の 3 重区別。主ボタン 56px 朱
S-03 partial (1i) 注意バナー、読めた文字チップ、「もう一度撮る」「このまま記録に残す」 警告色 #F4E6CF 系。位置なしメタの例も兼ねる
S-04 失敗 (1h) no_photography アイコン、説明、うまく撮るコツ 3 行、再撮影、ホーム 責めないトーン。中央揃え縦 flex
S-05 履歴 (1j/1k) 「旅の記録」見出し、件数、履歴カード、空状態 CTA カード横 flex。メモありバッジ（藍）。空は auto_stories
S-06 地図 (1l) MapLibre 地図、朱ピン、ポップアップカード、件数チップ、位置オフ配慮 淡色スタイル。ポップアップから S-03 へ
S-07 設定 ふりがな初期値、モード初期値、位置情報、データ削除、規約／免責 shadcn リスト。他画面の和紙×和色トーンに合わせる

結果画面の状態マトリクス

デザイン mode furigana 備考
1eeasyONやさしい＋ルビ表示
1feasyOFFやさしい・ルビ非表示
1gdetailOFFくわしい（ルビ OFF 例）
1i（任意）（任意）partial。バナー＋チップ

本文テキストはモードで別内容（AI が 2 種生成）。ルビは同一テキストの rt 表示切替でよい。初期値は settings.modeDefault / furiganaDefault。

デザイントークン（要約）

トークンHex用途

インタラクション要約

  • ホーム CTA → 撮影 → シャッター → ローディング（2 段階）→ 結果 or 失敗
  • セグメント／ふりがなは即時（〜200ms ease）
  • 写真タップでライトボックス拡大
  • 「記録に残す」後は履歴に出現。メモは保存後も編集可
  • アニメーション控えめ（ボトムシート 300ms ease-out 等）
  • レスポンシブ: 375px 基準、max-width 480px 程度で中央寄せ
