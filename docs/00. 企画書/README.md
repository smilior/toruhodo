# Handoff: 撮るほど — かざすと、やさしく教えてくれる

スマホカメラで石碑・案内板を撮影すると、AIがやさしい言葉で解説してくれるPWA（モバイルファースト・日本語UI）。撮影 → OCR＋AI解説 → 履歴保存（旅の記録帳）。

ターゲット：子育て世帯の親（30〜40代）、散歩好きの中高年、歴史好きの旅行者。中高年配慮で文字は大きめ（本文16px以上）。

## About the Design Files

このバンドルの `撮るほど UIデザイン.dc.html` は **HTMLで作られたデザインリファレンス**（見た目と挙動を示すプロトタイプ）であり、そのまま流用する本番コードではない。タスクはこのデザインを **ターゲットコードベースの環境で再現実装** すること。

**推奨環境：`nextjs-family-app-starter` スキル**（Next.js 16 App Router + React 19 + Tailwind CSS v4 + shadcn/ui + Turso/Drizzle + Better Auth + Vercel）をそのまま土台に使うこと。ユーザーがこのスキルを持っている前提。

デザインHTMLはブラウザで直接開ける。全10バリエーション（6画面＋状態違い）が1ページに並ぶ。各画面には `1a`〜`1l` のIDバッジ付き。

## Fidelity

**High-fidelity（hifi）**。色・タイポ・余白・角丸・状態は最終仕様。既存ライブラリ（Tailwind/shadcn）を使いつつピクセル単位で再現すること。ただし：

- 写真はすべて斜めストライプのプレースホルダー → 実装ではユーザー撮影画像
- カメラ映像・地図は実装ではライブコンテンツ（地図はMapLibre GL JS推奨）
- iOSステータスバー・ホームインジケータはモック演出。実装しない

## Interactions & Behavior

- ホーム「かざして解説」→ 撮影 → シャッター → ローディング（2段階）→ 結果 or 失敗
- 結果画面: セグメント切替は即時（フェード程度、200ms ease）。ふりがなトグルも即時反映。写真タップでライトボックス拡大
- 「記録に残す」→ 保存 → 履歴に出現。メモは保存後も編集可
- 失敗画面「もう一度撮る」→ 撮影画面に戻る
- アニメーション控えめ: ボトムシートslide-up 300ms ease-out、カードtap時 opacity/scale微変化。派手なトランジション不要
- タブは4画面切替（設定含む）。現在地はアイコンFILL＋朱
- レスポンシブ: 375px基準、max-width 480px程度で中央寄せにすると破綻しない

## State Management

- `scan`: idle → capturing → ocr(読み取っています) → generating(解説を作っています) → done | failed | partial
- `result`: { photo, title, date, location?, easyText, detailText, easyRuby, detailRuby, aiNote, ocrRaw, partialChars?, memo, saved }
- `settings`: { furiganaDefault, modeDefault, geoEnabled }
- ふりがな・モードは結果画面ローカル状態（初期値は設定から）
- 履歴はTurso（Drizzle schema: records テーブル — id, userId, photoUrl, title, easyText, detailText, aiNote, ocrRaw, lat?, lng?, placeName?, memo?, createdAt）
- 写真の保存先: Vercel Blob推奨

## AI連携（実装ガイド）

- 撮影画像をClaude API（vision）に送信し、1リクエストで: OCR原文 / タイトル / やさしい解説 / くわしい解説 / AI補足 / ふりがな付き版（`<ruby>` タグ入りHTML文字列）をJSONで返させる
- 部分読み取り: OCR信頼度が低い場合 `partial: true` と読めた文字列を返させ、1iのバナー＋チップを表示
- 失敗: テキストが検出できない場合 `failed: true` → 1h画面
- 免責注記は結果画面に常時表示
