01 要件定義 · 03/04

機能要件

撮るほど（toruhodo）が提供する機能・受け入れ基準・画面構成を定義する。

確定メモ

本ドキュメントの内容は企画書（docs/00. 企画書/README.md）および共有プロダクトブリーフ（docs/_spec/PRODUCT_BRIEF.md）を正本とする。

機能 ID は F-00〜F-09、画面 ID は S-00〜S-07。デザイン参照 ID は企画書の 1b〜1l を用いる。

受け入れ基準は各 MVP 機能の Definition of Done。Given-When-Then をすべて満たせば完成とみなす。スキャン状態機械: idle → capturing → ocr → generating → done | failed | partial。データは Turso（records）と Vercel Blob（写真）にユーザー単位で保存する。

機能一覧

ID 機能名 区分 概要 対応画面
F-00ログイン / ログアウト必須Better Auth + Google OAuth でサインイン。セッション Cookie を発行。ログアウトでセッションを破棄しログイン画面へS-00
F-01ホーム必須「かざして解説」CTA とさいきんの記録。1 タップで撮影へ。履歴への導線S-01
F-02撮影必須カメラビュー・ガイド枠・シャッター・ギャラリー・フラッシュ UI。撮影後は読み取りフローへS-02
F-03OCR＋AI 解説生成必須Claude Vision 1 リクエストで OCR 原文・タイトル・やさしい／くわしい解説・ルビ付き版・AI 補足・partial/failed を JSON で取得S-02, S-03, S-04
F-04解説結果必須モード切替（やさしい／くわしい）・ふりがな・メモ・記録に残す・免責常時表示。写真拡大S-03
F-05読み取り失敗・部分読み取り必須失敗時は責めない UI と撮り方のコツ・再撮影。部分読み取り時は注意バナーと読めた文字チップS-03, S-04
F-06旅の記録（履歴）必須履歴一覧・空状態・カードタップで結果画面へ。メモありバッジS-05
F-07旅の記録地図必須MapLibre でピン表示・ポップアップ。位置情報オフ時の配慮メッセージS-06
F-08設定必須ふりがな／モード初期値・位置情報 ON/OFF・データ削除・利用規約／免責S-07
F-09クラウド永続化必須records を Turso に、写真を Vercel Blob にユーザー単位で保存・復元全画面（要ログイン）

スキャン状態機械

状態 意味 UI 対応
idle撮影待機S-02 カメラ画面
capturingシャッター直後・画像確定中プレビュー確定
ocr読み取り中1d 段階1「読み取っています…」
generating解説生成中1d 段階2「解説を作っています…」
done正常完了S-03 結果（1e/1f/1g）
failedテキスト検出不可S-04 失敗（1h）
partial一部のみ読めたS-03 部分読み取り（1i）

遷移: idle → capturing → ocr → generating → done | failed | partial。キャンセル時は idle またはホームへ戻る。

受け入れ基準

機能ID ID Given(前提) When(操作) Then(期待結果)
F-00AC-00未ログインでアプリにアクセスする保護された画面（S-01 等）を開こうとするS-00 ログイン画面へ誘導される
F-00AC-00bS-00 を表示している「Google でログイン」を選び OAuth を完了するセッションが確立し、ホーム（S-01）へ遷移する。初回は記録 0 件の空状態
F-00AC-00cログイン済みログアウトを実行するセッションが破棄され、S-00 へ戻る。他ユーザーのデータは見えない
F-01AC-01ログイン済みホームを表示する「かざして解説」主役 CTA とタブバー（ホーム／履歴／地図／設定）が表示される
F-01AC-01bログイン済みで記録が 1 件以上ホームを表示するさいきんの記録が 2〜3 件表示され、「すべて見る」で履歴へ遷移できる
F-01AC-01cホームを表示している「かざして解説」を 1 タップする確認なしで S-02 撮影画面へ遷移する
F-02AC-02S-02 を表示しているカメラ権限を許可しシャッターを押す撮影プレビューが即時反映され、scan 状態が capturing → ocr に進む
F-02AC-02bS-02 を表示しているギャラリーから画像を選ぶ選択画像で OCR＋解説フローが開始される
F-02AC-02cS-02 を表示している閉じるボタンを押すホーム（S-01）へ戻る
F-03AC-03撮影画像が送信されたClaude Vision が成功応答するocr → generating → done（または partial）となり、タイトル・やさしい／くわしい・ルビ・AI 補足が揃う
F-03AC-03b撮影画像に文字が検出できないAI が failed: true を返すscan 状態が failed となり S-04 失敗画面へ
F-03AC-03cOCR 信頼度が低いAI が partial: true と partialChars を返すscan 状態が partial となり、結果画面に注意バナーと読めた文字チップが出る
F-04AC-04結果画面（done）を表示している「やさしい ⇄ くわしい」を切り替える本文が即時（〜200ms fade）に切り替わる。原文カードと AI 補足カードは色・アイコン・ラベルで区別できる
F-04AC-04b結果画面を表示しているふりがなスイッチを ON/OFF するルビ（rt）の表示が即時に切り替わる
F-04AC-04c結果画面を表示しているメモを入力し「記録に残す」をタップするrecord が保存され、履歴に出現する。免責注記が画面下部に常時表示されている
F-04AC-04d結果画面を表示している写真をタップするライトボックス等で拡大表示される
F-05AC-05読み取り失敗画面を表示している画面を確認する責めない見出し・説明、「うまく撮るコツ」3 項目、「もう一度撮る」「ホームにもどる」がある
F-05AC-05b失敗画面を表示している「もう一度撮る」をタップするS-02 撮影画面（idle）へ戻る
F-05AC-05c部分読み取り結果を表示している「このまま記録に残す」をタップするpartial フラグ付きで保存できる。「もう一度撮る」で再撮影できる
F-06AC-06ログイン済みで記録が 1 件以上履歴（S-05）を開く旅の記録一覧（サムネ・タイトル・日付・場所名・メモバッジ）が表示される
F-06AC-06b記録が 0 件履歴を開く空状態（まだ記録がありません）と撮影導線が表示される
F-06AC-06c履歴に記録があるカードをタップする該当の解説結果画面（保存版）へ遷移する
F-07AC-07位置情報付きの記録がある地図（S-06）を開くMapLibre 地図上にピンが表示され、タップでポップアップ→結果へ遷移できる
F-07AC-07b位置情報がオフ、または位置なし記録のみ地図を開く「位置情報がオフでも、記録は残せます」等の配慮 UI、または空状態＋設定導線が出る。地図タブ自体は残る
F-08AC-08設定（S-07）を開いているふりがな初期値・モード初期値を変更する次回の結果画面に初期値が反映される
F-08AC-08b設定を開いている位置情報の記録を OFF にする以降の新規記録に lat/lng/placeName が付かない。既存記録の参照は維持
F-08AC-08c設定を開いているデータ削除を確認のうえ実行する当該ユーザーの records（および関連 Blob）が削除される
F-09AC-09記録を保存した別端末または再ログイン後に履歴を開く同一ユーザーの Turso / Blob データが復元され、失われない。他ユーザーの記録は一切表示されない

画面遷移の概要

遷移の要点（実装・受け入れ時の正）:

  • 未ログインで保護画面へ → S-00 ログイン。Google OAuth 完了後 → S-01 ホーム
  • S-01「かざして解説」→ S-02。シャッター → ローディング（ocr → generating）→ S-03（done / partial）または S-04（failed）
  • S-03「記録に残す」→ 履歴に出現。メモは保存後も編集可
  • S-04「もう一度撮る」→ S-02（idle）。「ホームにもどる」→ S-01
  • タブ: S-01 ⇄ S-05 ⇄ S-06 ⇄ S-07。S-05 カード / 地図ピン → S-03（保存版）
  • ログアウト → S-00
