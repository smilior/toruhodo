01 要件定義 · 01/04

プロジェクト概要

撮るほど（toruhodo）の目的・背景・成功指標・体制・スコープ外・計画を定義する。

確定メモ

本ドキュメントの内容は企画書（docs/00. 企画書/README.md）および共有プロダクトブリーフ（docs/_spec/PRODUCT_BRIEF.md）を正本とする。ドメイン・UI・AI 連携の詳細は企画書を優先する。

個人開発の B2C コンシューマアプリ（PWA・モバイルファースト）。本番スタックは Next.js + Vercel + Turso + Better Auth + Google OAuth（GCP）+ Vercel Blob + Claude Vision + MapLibre。データはログインユーザー単位でクラウドに保存する。

スコープ外（OUT-01〜OUT-06）は AI・実装の境界線として厳守する。

アプリ概要

項目 内容
アプリ名撮るほど
プロジェクトコード名toruhodo
タグラインかざすと、やさしく教えてくれる
目的スマホカメラで石碑・案内板を撮影し、AI がやさしい言葉で解説する。撮影 → OCR＋AI 解説 → 履歴保存（旅の記録帳）→ 地図で振り返る体験を提供する。
背景石碑や案内板の難しい漢字・文言は、子どもや中高年にとって読みにくく、その場で理解しづらい。写真は残るが内容を忘れやすい。責めない失敗 UI と大きな文字で、その場の理解と旅の記録を両立する道具が必要。
想定利用者子育て世帯の親（30〜40 代）、散歩好きの中高年、歴史好きの旅行者。スマホ中心・日本語 UI。Google アカウントでログインする。
基盤Next.js 16 App Router（TypeScript）/ ホスティング: Vercel / DB: Turso（libSQL）+ Drizzle ORM / 認証: Better Auth + Google OAuth（GCP）/ ストレージ: Vercel Blob（写真）/ AI: Claude API（vision）/ 地図: MapLibre GL JS / UI: Tailwind CSS v4 + shadcn/ui。PWA・モバイルファーストの会員制 Web アプリ。

ID 指標 目標値 測定方法 評価時期

KPI-02解説表示後の「記録に残す」率50% 以上利用ログ（結果表示→保存）公開 1 ヶ月

KPI-04読み取り失敗後の再撮影率40% 以上失敗画面からの再撮影導線の計測受け入れ時参考
