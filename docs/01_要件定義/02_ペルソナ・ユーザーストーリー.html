01 要件定義 · 02/04

ペルソナ・ユーザーストーリー

撮るほど（toruhodo）の利用者像と、その利用者が求める行動を定義する。

確定メモ

本ドキュメントの内容は企画書（docs/00. 企画書/README.md）および共有プロダクトブリーフ（docs/_spec/PRODUCT_BRIEF.md）を正本とする。

ペルソナ（P-01〜P-03）およびユーザーストーリー（US-00〜US-11）はプロダクトブリーフに基づき確定済み。MVP 対象は US-00〜US-11 すべて（優先度は高・中・低あり）。

ストーリー形式は「〜として〜したい。〜のため」を維持する。受け入れ時は下記の受け入れ観点を判定基準とする。

ペルソナ

ID ペルソナ名 属性 困りごと ニーズ
P-01あかり30 代・子育て世帯の親 / 家族散歩 / スマホ中心難しい漢字・文言が子どもに説明できないやさしい言いかえ＋ふりがな
P-02たけし60 代・散歩好き / スマホは大きめ文字派案内板が読みにくい。失敗すると落ち込みやすい大きな文字・失敗しても責めない UI
P-03ゆい40 代・歴史旅 / 旅行で石碑を撮る写真は残るが内容を忘れる旅の記録帳＋地図で振り返り

ユーザーストーリー

ID ペルソナ ストーリー 優先度 MVP対象
US-00P-01あかりとして、Google でログインし自分の記録だけ見たい。端末を変えても同じ旅の記録を使うため高○
US-01P-01あかりとして、ホームから 1 タップで撮影を始めたい。子どもと歩きながらすぐ使えるため高○
US-02P-02たけしとして、石碑を撮るとやさしい解説が出てほしい。その場で内容を理解するため高○
US-03P-01あかりとして、ふりがなの ON/OFF を切り替えたい。子どもに読み聞かせるときと自分で読むときを分けるため高○
US-04P-03ゆいとして、やさしい／くわしいを切り替えたい。浅く知りたいときと深く知りたいときがあるため高○
US-05P-02たけしとして、うまく読めなくても次の撮り方を教えてほしい。責められず再挑戦できるため高○
US-06P-03ゆいとして、記録に残して後から履歴で見たい。旅のあとで内容を振り返るため高○
US-07P-03ゆいとして、地図上で訪れた場所を振り返りたい。どこを歩いたか視覚的に確認するため中○
US-08P-01あかりとして、自分のメモを書き足したい。子どもが言ったことや感想を残すため中○
US-09P-02たけしとして、位置情報をオフでも記録は残したい。プライバシーを守りつつ使えるため中○
US-10P-01あかりとして、ふりがな・解説モードの初期値を設定したい。毎回切り替えなくてよいため低○
US-11P-03ゆいとして、データを削除したい。不要になった記録やアカウント関連データを消すため低○

受け入れ観点（ストーリー単位）

ID 受け入れ観点
US-00未ログイン時は保護画面に入れない。Google OAuth 完了後、自分の records のみ表示。他ユーザーの記録は一切見えない。ログアウトでセッション破棄。
US-01ホームの「かざして解説」CTA を 1 タップで撮影画面（S-02）へ遷移する。追加の確認ダイアログは出さない。
US-02石碑・案内板の撮影後、OCR＋AI 解説が完了し、やさしい言いかえ（および AI 補足）が表示される。免責注記が常時表示される。
US-03結果画面でふりがなスイッチを切り替えると、本文のルビ表示が即時（〜200ms）に反映される。
US-04結果画面のセグメント「やさしい ⇄ くわしい」で本文が切り替わる。両モードの本文は AI が別内容として生成したものを用いる。
US-05読み取り失敗時は責めない文言と「うまく撮るコツ」、再撮影・ホーム導線を出す。部分読み取り時は注意バナーと読めた文字チップを出す。
US-06「記録に残す」で Turso に保存され、履歴一覧に出現する。再ログイン後も同一ユーザーのデータが復元される。
US-07位置情報付きの記録が地図上にピン表示される。ピンタップでポップアップ→結果画面へ遷移できる。
US-08結果画面でメモを入力・保存でき、保存後も編集できる。履歴カードに「メモあり」バッジが出る。
US-09位置情報拒否または設定でオフでも、解説・記録保存は可能。場所名は出さず日時のみ。地図は空状態または配慮メッセージを出す。
US-10設定でふりがな初期値・解説モード初期値を変更でき、次回以降の結果画面に反映される。
US-11設定からデータ削除を実行でき、自分の records（および関連写真）が削除される。確認ステップを経る。

リリーススライス

リリース 含むストーリー 目的
第1リリース(MVP)US-00〜US-11Google ログイン・撮影→AI 解説・ふりがな／モード切替・失敗／部分読み取り・旅の記録・地図・設定・クラウド永続化で「かざすと、やさしく教えてくれる」価値を検証
第2リリース以降（OUT 解除候補）オフライン OCR、共有アルバム、音声読み上げ等は OUT-01〜OUT-06 解除時に検討
