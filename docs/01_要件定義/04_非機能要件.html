01 要件定義 · 04/04

非機能要件

撮るほど（toruhodo）の品質目標・レスポンシブ方針・認証認可・プライバシー・PWA・法務要件を定義する。

確定メモ

本ドキュメントの内容は企画書（docs/00. 企画書/README.md）および共有プロダクトブリーフ（docs/_spec/PRODUCT_BRIEF.md）を正本とする。

MVP は Next.js + Vercel + Turso + Better Auth + Google OAuth + Vercel Blob + Claude Vision + MapLibre を前提とする品質目標。会員制・ユーザー単位データ隔離が必須。PWA・モバイルファースト。

中高年配慮（本文 16px 以上・タップ領域 44px 以上）と AI 免責の常時表示を品質の一部として扱う。

品質目標値

区分 項目 目標値 前提条件
性能UI 応答（解説生成待ちを除く）モード切替・ふりがな・タブ遷移など UI 操作は 200ms 級で反映クライアント側状態切替。AI 待ち時間は含まない
性能撮影プレビューシャッター後のプレビューは即時（体感ラグを感じさせない）カメラ API / ローカル画像。ネットワーク非依存
性能主要画面の表示初回・再訪とも 2 秒以内（中位帯スマホ・通常回線）を目標Vercel エッジ配信 + Server Components。モバイルファースト
性能AI 解説生成通常回線で数十秒以内を目安。2 段階ローディングで待ちを説明Claude API（vision）依存。タイムアウト・失敗時は再試行または失敗 UI
性能想定同時接続数個人向け小規模（同時数十ユーザー程度を快適に扱えること）Hobby / Free 枠での個人アプリ規模。大規模 B2B 負荷は対象外
性能データ増加見込みユーザーあたり記録数百件・写真同数規模を快適に操作Turso（libSQL）+ Blob。クエリは userId で絞る
可用性稼働率(SLO)Vercel 前提で 99.9% を目標。個人アプリとしてマネージド基盤の現実的稼働に準拠。計画メンテは事前告知Vercel / Turso / Claude API の SLA に依存。過剰な冗長化はしない
可用性復旧目標 RTO / RPORTO: 再デプロイ・設定復旧で数分〜数時間 / RPO: Turso バックアップ方針に準拠（日次相当を目標）ユーザーデータは Turso + Blob。コードは Git 管理
セキュリティ通信HTTPS 必須Vercel 既定
セキュリティ認証Better Auth + Google OAuth。セッション Cookie。メール / パスワードは提供しないGCP で OAuth クライアント管理
セキュリティデータ隔離すべての records / 設定は userId で所有。他ユーザーのデータは参照・更新不可Server Actions / Route Handlers でセッション検証必須
セキュリティ画像アクセス写真は認証ユーザー本人のみ参照可能（Blob URL の露出方針は認可設計で定める）未ログイン・他ユーザーからの直接閲覧を防ぐ
セキュリティ脆弱性診断公開前に依存パッケージ監査と認証・認可・XSS 観点の自己チェックを実施課金なし。個人アカウントと位置・画像を扱うため最低限の点検は必須
アクセシビリティ文字サイズ本文 16px 以上。メタ・注記は最小 12px中高年配慮。企画書タイポに準拠
アクセシビリティタップ領域最低 44px。主ボタン高さ 56px、シャッター 80px企画書 Design Tokens
プライバシー位置情報任意。拒否時も解説・記録は可能。場所名は出さない設定で ON/OFF。geoEnabled 既定 true
プライバシーデータ削除ユーザーが自分の記録・関連データを削除できる設定画面 F-08 / US-11
AI免責表示結果画面に「AI による解説です。正確な情報は現地の案内をご確認ください。」を常時表示企画書・プロダクトブリーフ必須
運用保守ログ保管期間Vercel のランタイムログはプラットフォーム既定に従う。個人を特定しうるログは最小限サーバーレス / マネージド
運用保守バックアップ頻度Turso 側のバックアップ・スナップショット機能を利用（利用可能プランに合わせる）ユーザーデータの正はクラウド DB + Blob
移行性既存データ移行無（新規アプリ）。スキーマ変更は Drizzle マイグレーションで管理本番 DB は Turso リモート
UXやさしく教える失敗 UI は責めない。原文と AI 補足を一目で区別。和紙×和色企画書デザイン原則に準拠

レスポンシブ・PWA・対応ブラウザ

項目 内容
スマートフォン320px〜767px 必須（プライマリ。375px 基準・モバイルファースト）
タブレット768px〜1023px 対応（レイアウトを崩さず利用可能）
デスクトップ PC1024px 以上対応（コンテンツをセンタリングし最大幅を制限。max-width 約 480px 中央寄せ推奨）
PWAインストール可能な PWA として提供（マニフェスト・アイコン朱印「撮」）。オフライン完全同期・オフライン OCR は OUT-02 で対象外
対応ブラウザモバイル Safari およびモバイル Chrome の最新 2 メジャーバージョンを主対象

認証・認可要件

項目 内容
会員制要（ログイン必須で自分のデータにアクセス）
認証方式Better Auth + Google OAuth のみ（MVP）。メール / パスワード登録は提供しない
OAuth 資格情報Google Cloud Console（GCP）でクライアント ID / シークレットを管理
セッション管理Better Auth のセッション Cookie。サーバー側セッション情報は Turso に保存
データ隔離すべての records・設定は userId で所有。他ユーザーのデータは参照・更新不可
画像Vercel Blob 上の写真は認証ユーザー本人のみアクセス可能とする
ロール 想定利用者 主な権限
ログインユーザーGoogle アカウントでサインインした本人自分の記録・設定の参照・登録・編集・削除。撮影と AI 解説。ログアウト

プライバシー・位置情報

項目 内容
位置情報の取得任意。ブラウザ権限拒否または設定 OFF 時も、解説生成と記録保存は可能
位置情報拒否時の表示結果画面は日時のみ（場所名なし）。地図は配慮メッセージまたは空状態＋設定導線
データ削除設定からユーザー自身の records（および関連写真）を削除できる。確認ステップを経る
収集データ例Google 経由のプロフィール、撮影画像、OCR／解説テキスト、任意の位置・メモ

項目 要否 備考
