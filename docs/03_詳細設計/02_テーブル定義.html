03 詳細設計 · 02/03

テーブル定義

撮るほどの物理テーブル定義と設計意図を記す。DB は Turso（libSQL）+ Drizzle ORM。正は src/lib/db/schema.ts および npm run db:push によるスキーマ適用である。

確定メモ

ドメインテーブルは records（旅の記録）と user_settings。認証は Better Auth 標準（users / sessions / accounts / verifications）。

写真バイナリは DB に持たず Vercel Blob URL（photo_url）のみ保持する。

failed は永続化しない（再撮影前提）。partial は records 行にフラグとして保存する。

正の所在

  • スキーマの正: src/lib/db/schema.ts（Drizzle）。
  • 適用: npm run db:push（ローカルは turso dev --db-file local.db 等）。
  • 論理設計の概要は 02_基本設計/05_DB設計.html。本書は物理寄り詳細である。

アプリ層ルール・制約

IDルール実装箇所
R-01partial と failed を同時 true にしない。failed 優先で正規化。failed は DB 行を作らないAI JSON パーサ／スキャン結果正規化
R-02partial = false のとき partial_chars は null（空文字は null へ）INSERT 前バリデーション
R-03lat と lng は両方 null か両方非 null。片肺は両方 null に正規化記録保存
R-04mode_default は easy | detail のみ設定 upsert
R-05すべての records 読み書きは user_id = session.user.idServer Actions
R-06ruby HTML は許可タグのみ保存（サニタイズ後）AI 応答処理
R-07ユーザー削除時: records / user_settings / sessions / accounts は FK CASCADEDB FK
R-08データ全削除（設定）: 当該 user の records 全削除＋ Blob 掃除＋ settings リセット。users 行は残す削除 Action

SQLite / libSQL では CHECK で boolean 組み合わせを強制しにくいため、アプリ層バリデーションを正とする。必要なら後続で CHECK を追加してよい。

Drizzle スキーマ擬似コード

// src/lib/db/schema.ts（擬似・抜粋）
import { relations } from "drizzle-orm";
import {
  index,
  integer,
  real,
  sqliteTable,
  text,
} from "drizzle-orm/sqlite-core";

// --- Better Auth（要約。公式アダプタ定義に準拠）---
export const users = sqliteTable("users", {
  id: text("id").primaryKey(),
  name: text("name").notNull(),
  email: text("email").notNull().unique(),
  emailVerified: integer("email_verified", { mode: "boolean" })
    .notNull()
    .default(false),
  image: text("image"),
  createdAt: integer("created_at", { mode: "timestamp" }).notNull(),
  updatedAt: integer("updated_at", { mode: "timestamp" }).notNull(),
});

export const sessions = sqliteTable(
  "sessions",
  {
    id: text("id").primaryKey(),
    userId: text("user_id")
      .notNull()
      .references(() => users.id, { onDelete: "cascade" }),
    token: text("token").notNull().unique(),
    expiresAt: integer("expires_at", { mode: "timestamp" }).notNull(),
    ipAddress: text("ip_address"),
    userAgent: text("user_agent"),
    createdAt: integer("created_at", { mode: "timestamp" }).notNull(),
    updatedAt: integer("updated_at", { mode: "timestamp" }).notNull(),
  },
  (t) => [index("sessions_user_id_idx").on(t.userId)],
);

export const accounts = sqliteTable("accounts", {
  id: text("id").primaryKey(),
  userId: text("user_id")
    .notNull()
    .references(() => users.id, { onDelete: "cascade" }),
  accountId: text("account_id").notNull(),
  providerId: text("provider_id").notNull(),
  accessToken: text("access_token"),
  refreshToken: text("refresh_token"),
  // … Better Auth が要求するその他トークン列
  createdAt: integer("created_at", { mode: "timestamp" }).notNull(),
  updatedAt: integer("updated_at", { mode: "timestamp" }).notNull(),
});

export const verifications = sqliteTable("verifications", {
  id: text("id").primaryKey(),
  identifier: text("identifier").notNull(),
  value: text("value").notNull(),
  expiresAt: integer("expires_at", { mode: "timestamp" }).notNull(),
  createdAt: integer("created_at", { mode: "timestamp" }),
  updatedAt: integer("updated_at", { mode: "timestamp" }),
});

// --- ドメイン ---
export const records = sqliteTable(
  "records",
  {
    id: text("id").primaryKey(),
    userId: text("user_id")
      .notNull()
      .references(() => users.id, { onDelete: "cascade" }),
    photoUrl: text("photo_url").notNull(),
    title: text("title").notNull(),
    easyText: text("easy_text").notNull(),
    detailText: text("detail_text").notNull(),
    easyRuby: text("easy_ruby").notNull(),
    detailRuby: text("detail_ruby").notNull(),
    aiNote: text("ai_note").notNull(),
    ocrRaw: text("ocr_raw").notNull(),
    partial: integer("partial", { mode: "boolean" }).notNull().default(false),
    partialChars: text("partial_chars"),
    lat: real("lat"),
    lng: real("lng"),
    placeName: text("place_name"),
    memo: text("memo"),
    createdAt: integer("created_at", { mode: "timestamp" }).notNull(),
  },
  (t) => [
    index("records_user_id_idx").on(t.userId),
    index("records_user_created_idx").on(t.userId, t.createdAt),
  ],
);

export const userSettings = sqliteTable("user_settings", {
  userId: text("user_id")
    .primaryKey()
    .references(() => users.id, { onDelete: "cascade" }),
  furiganaDefault: integer("furigana_default", { mode: "boolean" })
    .notNull()
    .default(true),
  modeDefault: text("mode_default").notNull().default("easy"), // "easy" | "detail"
  geoEnabled: integer("geo_enabled", { mode: "boolean" })
    .notNull()
    .default(true),
  updatedAt: integer("updated_at", { mode: "timestamp" }).notNull(),
});

export const usersRelations = relations(users, ({ many, one }) => ({
  records: many(records),
  settings: one(userSettings, {
    fields: [users.id],
    references: [userSettings.userId],
  }),
}));

export const recordsRelations = relations(records, ({ one }) => ({
  user: one(users, {
    fields: [records.userId],
    references: [users.id],
  }),
}));
